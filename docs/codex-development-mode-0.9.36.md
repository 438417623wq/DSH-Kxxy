# Codex 开发模式适配 · 0.9.36

目标版本为 0.9.36，Android versionCode 为 936000。本次解决旧聊天持续停留在无工具模式，以及开发模式入口不够明显的问题。

## 为什么开发环境完善，模型仍说不能操作

截图上方显示“对话模式”，底部显示“仅对话，不执行操作”，说明当前会话没有向模型提供文件和命令工具。旧版本点击新建对话，或再次使用同一个自定义模型时，可能继续采用之前的聊天模式；恢复历史也会保留原模式。模型是否拿到工具与设备是否装有完整开发环境是两个独立条件。

## 使用方式

1. 输入框上方明确展示“工作区助手 / 仅聊天”。新建自定义模型会话默认选择工作区助手。
2. 旧聊天显示“当前是仅聊天模式，开发工具未启用”。点击“启用开发工具”，即可在新的工作区助手会话中继续。
3. 启用时保留同一自定义模型、DSH 会话及工作目录、已完成的聊天上下文、当前草稿和引用文件。不会自动发送草稿或重跑此前任务；原聊天仍可从历史恢复。
4. 描述需要执行的任务。助手可直接查看目录、读取和搜索文件；修改文件及每条命令仍需点击确认卡片中的“本次允许”。
5. 主动选择“仅聊天”仍可进行纯文本对话。恢复旧聊天保持它原有的模式，并显示相应提示。

切换模式时不直接改变已有会话的工具权限。续接会创建独立会话，并只继承已完成的上下文；正在运行的任务需先停止或完成。助手回复的标题、列表、强调及代码会安全排版，模型文本不会作为 HTML 执行。

## 开发环境检查

展开顶部工作区，或进入“设置 → 开发环境”，点击“检查开发环境”。该动作实际检查工作目录访问，在工作区创建独占的随机临时文件并写入、读回、删除，同时使用当前应用开发环境运行固定的终端、Node、Python 和 Git 探测。

结果逐项展示通过或错误，并在切换 DSH 会话或工作目录后清除，避免显示旧环境的检查结论。检查不修改已有项目文件，也不向模型服务发送请求。

环境检查通过表示这些本地能力可用；它不代表模型服务的函数调用已通过测试。“测试模型”验证短文本推理连接；实际工作区操作还要求模型支持所选 Chat Completions 或 Responses 接口的函数调用。

自定义助手继续使用应用普通权限，不提供提权或额外的操作系统沙箱。Android 无权访问的路径仍不能访问；原生 Codex CLI 的本机隔离验证保持原逻辑。
