# 0.9.29 启动救援说明

## 覆盖安装

使用 `dist/Kxxy-0.9.29.apk` 覆盖安装。不要卸载，不要清除应用数据。安装包保持项目固定签名，版本代码为 `929000`。

## 引擎和控制台都打不开时

1. 在启动页点 **诊断/救援**。该菜单为原生界面，不依赖 Node、3080 服务或 WebView。
2. 先点 **查看脱敏启动日志**；可选择 **保存日志**，文件默认仅保存在选择的位置，不自动上传。
3. 点 **诊断启动原因**。启动/安装还在进行时会先确认停止，等待旧任务结束，再只读诊断。诊断有超时和取消入口。
4. 若明确显示运行时缺失/损坏，可使用 **离线修复运行时**：从当前 APK 解包，先检查剩余空间，保留 home/profile、模型配置、会话、工作区及用户扩展。
5. 若明确命中某份配置，修复只处理对应层。**高级配置修复** 可调整第三方启用列表；L3 仍是重建插件依赖，不是重装运行时，需要联网及确认。

## 保护和限制

- 未知故障、权限、空间或 ABI/JNI 兼容问题，不再自动搬走合法个人配置。
- 配置修改先记录备份；撤销遇新文件冲突时保留双方和备份，不覆盖新改动，也不假称全部成功。
- 运行时重装只恢复 APK 管理的文件，不备份整个运行时，所以该动作不可撤销。个人配置修复记录仍可撤销。
- 修复动作结束后仍要验证启动；只有引擎实际就绪才显示启动修复成功。
- 慢设备启动等待延长到有界的 120–180 秒；非核心 TeX/工具维护在引擎就绪后执行，有超时，不再阻塞进入主界面。
- 原生库、ABI/ROM 或 WebView 不兼容可能需要系统组件更新或另行修复，离线解包不是万能解决方案。再次失败请保存新的脱敏日志。

## 验证范围

主机编译与 Kotlin/Node 行为回归不能代替失败手机的覆盖安装验证。本次不自动安装到已连接设备，不执行 `pm clear`。最终测试、安装包签名与资产校验结果另见 `dist/Kxxy-0.9.29-verification.json`。
