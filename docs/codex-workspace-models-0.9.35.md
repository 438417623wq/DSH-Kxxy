# Codex 自定义工作区助手 · 0.9.35

本次修复自定义模型只能文字对话、无法主动查看当前工作环境的问题，并更新手机侧栏的模型设置界面。

## 使用

1. 在当前 DSH 工作区打开 Codex 侧栏，进入“设置”。
2. 输入服务 URL、API 密钥并选择接口格式，点击“获取模型”，搜索并选择模型；服务不提供列表时可手动填写模型 ID。
3. 点击“测试模型”查看实际回复和响应时间，再保存并使用。
4. 新建对话默认使用“工作区助手”。可让模型查看目录、读取或搜索文本文件。文件修改和每条命令会先展示确认卡片。
5. 使用“本次允许”或“拒绝”处理操作；“停止”会取消请求、待处理确认和运行中的命令。切换“对话”模式会新建对话。

编辑已有模型时，密钥留空保留原值，获取和测试也可复用已保存密钥。测试仅发送一条简短消息，不附带对话历史或工作区工具；获取、测试和正常对话都会使用用户指定的服务。

## 环境访问

自定义助手直接绑定当前 DSH 会话实际工作目录，使用应用 Node 进程执行真实工具。两种接口均支持函数调用分片、工具结果回传和后续回答；模型必须支持所选接口的函数调用才能主动操作工作区。

文件读取限定在绑定工作区，屏蔽凭据文件、越界路径、外部符号链接和多链接文件。写入前展示完整旧内容和新内容差异，确认后重新检查路径和文件摘要；审批期间文件被修改时拒绝覆盖。每次命令执行需要单独确认，命令使用应用普通权限，没有额外的操作系统沙箱，也不会提权。Android 的应用路径访问限制仍适用。

命令启动时只传递运行工具所需的环境，排除账号密钥和任意 Node 预加载配置，保留已有 Android 运行时重定位组件。工具结果、搜索量、命令输出与执行时间均有上限；截断和超时会显示在结果中。

原生 Codex CLI 路径及本机隔离检查保持原逻辑；本 APK 不附带尚未通过 Android 隔离验收的 Codex CLI。自定义模型的工作区工具独立可用。

## 验证范围

本地 HTTP 测试验证 Chat Completions 与 Responses 的流式函数调用、真实临时工作区文件与命令操作、审批隔离和取消、持久化历史与请求去重。模型服务测试覆盖未保存配置、复用密钥、鉴权错误、超时与无效服务响应。

Chrome 浏览器加载实际客户端与后端，已验证获取失败重试、搜索选模、测试反馈、保存密钥清空、真实目录与文件读取、文件差异确认、命令确认、停止审批、模式切换与历史恢复。390 px 与 320 px 手机布局无横向溢出，并已查看设置、对话及审批截图。

APK 打包检查覆盖运行时资产、插件源码一致性、升级版本号、固定签名与原有启动修复。未使用用户真实服务密钥做在线验证，也未自动安装到手机。

接口参考：[OpenAI 函数调用文档](https://developers.openai.com/api/docs/guides/function-calling)、[流式回复文档](https://developers.openai.com/api/docs/guides/streaming-responses)。
